# MIT 18.06 Linear Algebra

Self-directed study using the materials from
[MIT OpenCourseWare 18.06 Linear Algebra](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/).

## Purpose

To build the linear algebra foundation required for the MITx MicroMasters
in Statistics and Data Science and future computational neuroscience work.

## Topics covered

- Linear systems, elimination, and matrix factorisation
- Vector spaces, subspaces, rank, and null spaces
- Orthogonality, projections, and least squares
- Eigenvalues, eigenvectors, and diagonalisation
- Symmetric and positive-definite matrices
- Singular value decomposition and basic dimensionality reduction
