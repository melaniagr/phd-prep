# Stanford Fundamentals of ML for Healthcare - Notes Summary

Handwritten notes + key takeaways. Focus: Healthcare ML pitfalls (bias, eval, ethics).

## Modules Overview

### 1. Why ML in Healthcare?
- History: AI waves, MIMIC dataset.
- Need: High-variance data, personalization (imaging/EHR).
- Limits: Biostats + domain ("No Free Lunch").

### 2. ML Principles
- Supervised: Regression/classification.
- Unsupervised: Clustering/PCA.
- Jargon: Overfitting, splits.

### 3. Deep Learning
| Arch | Use | Key |
|------|-----|-----|
| CNN | Imaging | Convolution |
| RNN/LSTM | Time-series | Sequential |
| Transformer | Notes | Attention |
| Loss/Grad Desc | All | Backprop |

### 4. Evaluation Metrics
- Imbalanced: AUROC/PR/AUPRC.
- Calibration/Brier; reg/overfit.

### 5. Clinical Challenges
- Missingness/leakage/bias ("shelf life").
- Timelines, interpretability (SHAP).

### 6. Best Practices
- OAP framework, teams, ethics (bias, FDA).
